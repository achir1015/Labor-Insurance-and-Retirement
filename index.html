把勞保局網站的表格轉成 XML 片段

用法：不要把網頁的表格直接貼到下面的欄位，因為大部分瀏覽器直接複製表格時會弄丟欄位結構 （每一格文字會各自變成一行，不是一列一筆）。正確作法是：先把 edesk.bli.gov.tw 上的表格選取起來複製，貼到 Google Sheets 或 Excel 的空白列， 這樣表格會正確還原成一列一筆、欄位對齊；接著只選取需要的那幾欄、複製，再貼到下面的欄位。 這個工具只在你的瀏覽器裡把文字轉成 XML，不會送出任何資料。轉好之後，把產生的片段貼回你自己保存的主 XML 檔案裡對應的位置即可。

欄位之間請務必用 Tab 分隔（從 Google Sheets／Excel 複製貼上就會自動是 Tab），不要用逗號——金額常有千分位逗點，逗號分隔會把數字拆錯。

這個系統在做什麼

這是一個查詢頁面，用來瀏覽你自己整理的勞保、就保、國保與勞退資料。登入之後， 資料會存進你自己 Firebase 專案裡的 Firestore 資料庫（只有登入這個帳號的人看得到，不是公開資料庫）， 換電腦、換瀏覽器登入同一個帳號也能看到一樣的資料。資料來源不是即時連線勞保局，而是你自己從 edesk.bli.gov.tw 網站上手動複製、整理好之後，用「選擇 XML 檔案匯入」或「資料轉換小工具」放進系統， 再按「儲存到雲端」存起來。

  • 「儲存到雲端」會把畫面上目前的資料整份覆蓋掉雲端原本存的內容，請確認資料是對的再按。
  • 「從雲端重新載入」可以放棄畫面上還沒存檔的修改，重新讀回雲端上次存的版本。

用網址參數自動載入資料

如果你把自己的 XML 檔案放在一個可以直接打開、且允許跨網站讀取（CORS）的網址上 （例如 GitHub 上的 raw 檔案連結、Gist 的 raw 連結，或是你自己網站上的一個檔案）， 可以在這個頁面的網址後面加上 ?data= 參數，頁面打開時就會自動抓那個網址的內容來顯示， 不用每次手動選檔案。例如： 

index.html?data=https://raw.githubusercontent.com/你的帳號/你的repo/main/我的勞保資料.xml
  • 網址裡的網址要用 encodeURIComponent(...) 編碼一次，避免特殊符號被誤判。
  • Google Drive 分享連結大多不支援 CORS，直接放上去通常會讀取失敗；GitHub raw 連結一般可以正常運作。
  • 如果自動載入失敗（例如該網址不允許跨站讀取），頁面上方會顯示錯誤訊息，並繼續顯示範例資料，不影響你手動選檔案的用法。
  • 因為資料是用 fetch 從指定網址取得，內容仍留在你的瀏覽器裡處理，這個頁面本身不會把資料送到任何其他伺服器。

整份資料放在一個 XML 檔案裡，結構大致如下——「勞保就保記錄」的欄位直接對應勞保局網站上「勞工保險最新異動紀錄」那張表格：

    <資料更新日期>2026-09-01</資料更新日期>

    <官方國保年資>0年8個月</官方國保年資>
  </基本資料>

  <勞保就保記錄>
    <記錄>
      <序號>1</序號>
      <保險證號>01010351A</保險證號>
      <投保單位名稱>...</投保單位名稱>
      <勞就保投保薪資>36300</勞就保投保薪資>
      <災保投保薪資>36300</災保投保薪資>
      <生效日期>2018-07-01</生效日期>

      <單位欠費註記></單位欠費註記>
    </記錄>

  </國保記錄>

        <生效日期>2005-10-13</生效日期>
        <月提繳工資>30300</月提繳工資>
        <提繳身份別>1.強制提繳對象</提繳身份別>

      </記錄>
      ...
    </提繳異動紀錄>
  </勞退專戶>
</勞保勞退查詢資料>
  • 「勞就保投保薪資」是勞保／就保共用的投保薪資級距；「災保投保薪資」是職業災害保險自己的級距（2022 年改制後，職災保險的級距上限比一般勞保高，所以這兩欄數字常常不一樣）。
  • 「退保日期」留空代表目前仍在保。同一家公司如果只是調薪，勞保局會列成新的一列、生效日期不同，但通常不會有退保日期——只有真的離職才會填退保日期。
  • 「官方投保年資」「官方國保年資」是選填欄位，直接把勞保局總覽頁顯示的年資數字填進去，填了之後總覽頁卡片會優先顯示這個真正準確的數字，不用就留空，系統會改顯示簡易估算值（並註明是估算，不是官方數字）。
  • 「國保記錄」是逐筆的納保／退保事件，不是區間——總覽頁會自動把「納保」跟後面最近一筆「退保」配對，算出涵蓋天數；如果最後一筆是「納保」沒有對應退保，會算到今天（代表目前仍在保）。
  • 「提繳異動紀錄」裡每次雇主變更或提繳工資調整都會多一筆，雇主提繳率通常固定 6%；當月實際提繳金額大致是「月提繳工資 × 提繳率」，但目前系統沒有自動幫你算出每月金額，只是原樣列出異動紀錄。
  • 金額欄位都填純數字，不要加逗號或「元」；用「資料轉換小工具」貼上原始表格時，千分位逗點跟民國日期會自動幫你轉好。
  • 用「資料轉換小工具」分頁可以把你複製的表格快速轉成 <記錄> 片段，貼進主檔案就好，不用整段手打。
  • 總覽頁的「總投保年資」是從最早一筆生效日期，算到最後一筆的退保日期（或今天，如果還在保）——如果你不同工作之間其實有間隔（例如待業期間），因為原始表格通常不會特別標出這種間隔，這個估算會把間隔也算進去，正式年資還是要以勞保局公告為準。
